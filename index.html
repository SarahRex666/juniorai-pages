JuniorAI

A private household AI assistant

Built for one household, not the public

JuniorAI is a small AI assistant that runs on hardware in its owners' home. There's no public account system to sign up for — it only responds to requests from inside the household's own network.

What it does

Conversation

Answers questions and helps with everyday tasks through a chat interface, powered by a language model running on local hardware.

Web search

Looks things up in real time when a question needs current information, using Brave's search API.

Calendar

Views, creates, edits, and deletes events on a connected Google Calendar, with explicit permission from its owner.

How it's run

JuniorAI runs entirely on a computer in its owners' home. It isn't hosted in the cloud, and conversations aren't sent to a third-party AI provider — the language model itself runs locally. It's reachable only from devices already on the household's own networks.
